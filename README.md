# Hi, I'm Tasdiqul Islam

PhD Candidate in Computer Science at The University of Texas at Arlington, working on quantum networking, reinforcement learning, distributed systems, and network optimization.

My research focuses on scalable routing and resource allocation for quantum networks using deep reinforcement learning, fidelity-aware path selection, entanglement swapping, and large-scale simulation.

Previously, I worked as a Senior Software Engineer, building backend services and scalable systems using Java, Spring Boot, Python, MySQL, and distributed service architectures.

## Research & Engineering Interests

- Quantum networking and quantum communication systems
- Deep reinforcement learning for routing and scheduling
- Distributed systems, backend engineering, and scalable infrastructure
- Network optimization, simulation, and resource allocation
- Python, Java, Spring Boot, TensorFlow/Keras, NetworkX, Gurobi, FastAPI, MySQL

## Selected Projects

- QuRA: Deep reinforcement learning-based routing framework for quantum networks
- AEG: Adaptive entanglement generation for quantum routing
- GHZ-QKD Simulation: Quantum key distribution simulation using GHZ states
- MinRepeater / RepAlloc: Quantum repeater placement and resource allocation
